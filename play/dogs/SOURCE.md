# Kennel portraits

These six transparent PNG portraits were generated with the built-in imagegen
tool for Bellwether. Each prompt requested a natural, photorealistic head-and-
chest portrait, soft daylight, a three-quarter view facing slightly right,
transparent margins, and no text, logos, scenery, or watermark.

| File | Prompt subject and neckerchief |
|---|---|
| `collie.png` | Black-and-white Border Collie, red neckerchief |
| `corgi.png` | Tan-and-white Pembroke Welsh Corgi, blue neckerchief |
| `aussie.png` | Blue-merle Australian Shepherd with blue and brown eyes, moss-green neckerchief |
| `kangal.png` | Sandy Anatolian Kangal with dark face mask, dark-brown neckerchief |
| `puli.png` | Black corded Puli, golden-yellow neckerchief |
| `husky.png` | Silver-gray and white Siberian Husky with ice-blue eyes, arctic-cyan neckerchief |
